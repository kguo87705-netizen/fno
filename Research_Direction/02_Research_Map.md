# 02 技术地图：FNO具体替代什么

## 读图前先分清三个量

\[
\underbrace{m}_{\text{声速/厚度/材料}}
\xrightarrow{\mathcal G_{s,b}}
\underbrace{u}_{\text{波场}}
\xrightarrow{\mathcal R_\Gamma\;\text{与探头响应}}
\underbrace{d}_{\text{接收信号}}
\xrightarrow{\mathcal I}
\underbrace{I}_{\text{成像结果}}.
\]

\(s\)是源，\(b\)是边界，\(\Gamma\)是接收位置。若改变它们，必须纳入输入或明确限定；只输入介质的网络不能识别未提供的源变化。

```text
超声检测
├─ 正演：m,s,b → u → d
│  ├─ FEM：复杂弹性结构；P08用其生成标签
│  ├─ FDTD/FD：P01声学、P05/P06薄板
│  ├─ k-Wave：声学入门可选求解器，本地没有独立方法全文
│  └─ 学习代理
│     ├─ FNO基础 B01；PINO基础 B02
│     ├─ P05 双阶段FNO：厚度→面外时空场
│     ├─ P06 U-FNO：厚度+初始场→面外时空场
│     ├─ P08 PTUNet：不是FNO
│     └─ P09 FEUNet、P10 PINN：医学声学方法对照
├─ 成像：d → I
│  ├─ DAS/TFM：按传播时延累加；P01/P04有比较
│  ├─ SAFT：合成孔径；本轮只作概念位置
│  ├─ RTM/迁移：需要传播模型；本地尚缺直接FNO证据
```

## 六类方法不能混称

|方法|学习对象|物理怎么进来|本地依据|
|---|---|---|---|
|普通FNO|函数到函数的参数族映射|可只有数值标签|B01|
|PINO|PDE族解算子，可选单例微调|数据与PDE残差|B02|
|PINN/PIFNN|通常为单实例坐标到场|AD残差+IC/BC；Fourier特征增强|P02/P10|
|FEUNet/PTUNet|场到场回归|FD残差|P08/P09|
|直接逆FNO|信号到材料图|P01/P07主要监督标签|P01/P07|
|DeepONet|输入函数编码与查询坐标编码结合|可有物理约束|本地基础全文缺失；外部E02补充|

## FNO最自然的三个进入位置（本轮判断）

1. **重复正演代理。** 相同域、模态与激励族内，对大量不同材料/缺陷快速预测。证据最直接为P05/P06；频域只输出实虚场可降低入门存储量。
2. **受约束的少标签正演。** 以P05/B02为FNO依据，以P09为强非FNO基线，测量相同标签预算、相同算力下谁更可靠。
3. **条件明确的逆映射或反演代理。** P01/P07已有直接反演；新的问题必须落到采集偏移、相位/幅值误差或梯度可靠性。

## 对“FNO + TFM”的结构判断

标准TFM在给定传播模型下可写为
\[
I(\mathbf x)=\sum_{i,j}w_{ij}(\mathbf x)d_{ij}\bigl(\tau_i(\mathbf x)+\tau_j(\mathbf x)\bigr).
\]

- `FMC→FNO→缺陷图` 是学习成像，若没有时延累加模块，就不应名为TFM。
- `稀疏FMC→FNO补全→TFM` 在接口上清楚，但须测相位/走时误差与幻觉缺陷；还要对比直接用稀疏FMC成像。
- `材料→FNO波场→取接收迹→TFM` 是已知模型生成合成数据的验证流程，不能从未知缺陷自动取得前向模型输入；标准TFM本身并不需要完整正演波场。
- `FNO→传播时间/Green函数→成像` 应先定义成像算子；用完整Green函数的匹配/迁移不一定还是传统TFM。

## 分辨率与几何边界

跨参数、跨源、跨网格、跨采样率、跨几何、跨物理模型是六种不同测试。B01/B02的网格实验不能为P01的固定尺寸投影背书。规则矩形域内厚度变形（P05/P06）不等于带孔或曲面计算域；Geo-FNO等用于后者的适配见外部E01/E02。FNO谱层截断限制中间表示，非线性仍可生成高频；也不能说FNO只能处理周期边界。

图/网格路线已补核对E05 GINO：用图神经算子在非规则点与规则潜在网格之间映射，在潜在网格运行FNO。它提供网格输入的技术路线，但UT中仍须验证自由表面、曲面和材料界面条件。详见[补充一手来源](External_Check.md)；本轮未精读GINO全部实验，不为其填入本地核心矩阵的未核实字段。
