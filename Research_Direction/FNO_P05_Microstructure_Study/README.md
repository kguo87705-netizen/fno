# FNO → P05 双阶段 → 多晶材料水浸超声反演：学习入口

整理日期：2026-09-17。对象：已学高数、线代，刚开始接触 FFT、PDE 和 PyTorch 的本科生。

## 先回答你的研究问题

**可以把 FNO 作为候选方法引入目标问题，但目前只能说“值得验证”，不能说已经证明可行。** 最自然的切入点是学习“材料参数 → 超声波形”的正演映射，再评估它能否参与反演。P05 提供了物理损失与误差修正的设计参考；它的薄板方程、训练数据和网络权重不能直接用于多晶材料水浸体波问题。

本次交付是精读讲义、学习顺序和验证方案，尚未训练网络或复现反演。文章的方法事实、教学推导和我们提出的方案均分别标注。不会把“拼接两篇方法”当作已经成立的创新。

## 三篇论文，一条主线

| 文章 | 学习时要回答的问题 | 本轮角色 |
|---|---|---|
| B01：Fourier Neural Operator for Parametric Partial Differential Equations | 如何学习函数到函数的映射？傅里叶层为什么能交流全局信息？ | 基础方法 |
| P05：A dual-stage Fourier neural operator for Lamb wave scattering with physics embedded and residual refinement | 如何把基础方法用于波场，并加入物理约束与误差修正？ | 方法实例 |
| npj Computational Materials 12, 288 (2026) | 一个真实的科研反问题需要怎样的正演模型，代理模型要通过哪些检验？ | 迁移目标 |

目标论文的准确标题是 *Subsurface polycrystalline microstructure reconstruction via immersion ultrasound full waveform inversion*。见[出版社原文](https://link.springer.com/article/10.1038/s41524-026-02150-6)。

## 建议分成八课，不要求一次读完

| 课次 | 核心内容 | 完成标准 |
|---|---|---|
| 1 | 场、PDE、正演、反演、算子 | 能区分一张材料图、一个求解器、一组网络权重 |
| 2 | 傅里叶分解、复数系数、FFT | 能解释波数、频率、相位和采样的区别 |
| 3 | FNO 的提升—傅里叶层—投影 | 能写出一层的计算及张量形状 |
| 4 | PyTorch 最小训练流程 | 能说明损失、反向传播、训练/验证/测试划分 |
| 5 | P05 的薄板物理与网络 | 能解释为何它不能完整描述水浸各向异性体波 |
| 6 | 两种残差与实验批判性阅读 | 能分清 PDE 残差、预测误差、相对误差降幅 |
| 7 | FWI 与可微正演代理 | 能解释波形准确不等于梯度准确 |
| 8 | 迁移方案与最小实验 | 能设计一个可能失败、也能解释失败原因的检验 |

时间以理解程度为准。对当前基础，不把“几周内复现完整各向异性水浸 FWI”作为承诺。先完成可解释的小实验，比直接堆叠三篇论文更有价值。

## 今天先学到这里就合格

请先读 01 的第 1—5 节，完成三个问题：

- 一张厚度图为什么可以看成一个函数？
- 如果激励改变却没有告诉网络，原来的输入是否足以唯一确定波场？
- FFT 做完以后，神经网络究竟还要学习什么？

答案分别是：网格记录了函数在各点的采样；通常不够；学习各傅里叶模式上的通道变换及整个非线性映射，而不是学习 FFT 算法本身。
