# 较大材料扰动接受式混合对照 2026-10-11

## 结果判断

把目标材料参数从 `.48/.52` 扩大到 `.44/.56` 后，`a=.44` 一侧仍受三次 `±.02` 步长裁剪影响，区分度有限；`a=.56` 一侧显示出更有信息量的差异：冻结 R2 方向在两个深度都优于名义常数割线，但逐步重算物理方向仍然更准且更贵。

## 主要结果

| 深度/目标 | FNO冻结方向 | 名义常数割线 | 物理重算方向 |
|---|---:|---:|---:|
| -1 / .44 | 0 | 0 | 0 |
| +1 / .44 | 0 | 0 | 0 |
| -1 / .56 | `7.91e-4` | `1.99e-3` | `2.45e-4` |
| +1 / .56 | `1.80e-3` | `2.08e-3` | `2.44e-4` |

表中为最终真实物理接收相对失配。FNO和名义割线每个案例使用4次在线物理正演，重算物理方向使用10次；观测生成调用单独记录。所有候选都经过严格下降接受规则，三次更新固定，不按真值停止。

## 能支持的结论

- 在较大正向材料扰动的一侧，FNO冻结方向开始显示出超过名义割线的波形拟合效果。
- 这种优势只出现在两个已使用开发深度和一个方向（`.5→.56`）；`.44` 方向被步长上限限制，不能作为强证据。
- 物理重算方向仍明显更优，说明代理主要提供低调用候选，而不是替代物理导数。
- 当前仍没有完整训练、推理、正演纠正和数据生成的同质量总成本计算；不能称加速。

## 反方审查

目标偏移 `.06` 恰好等于三次最大步长，`.44` 一侧出现零误差可能来自裁剪和离散标量结构，不能泛化。`.56` 一侧 FNO优于名义基线，但两个深度和一个材料方向不足以排除偶然性；也没有比较多个支持位置或未见工件。成功标准仍是物理接收失配，不能替代材料恢复和独立测试。

## 下一步

优先扩展到不被步长上限整齐命中的目标（例如 `.53/.57`）和第二个已知支持状态，固定相同接受规则；若 FNO 在多数状态继续超过名义割线，才测量训练与在线纠正成本。若优势消失，应停止网络复杂度扩展，保留名义割线和物理验收作为基线。
