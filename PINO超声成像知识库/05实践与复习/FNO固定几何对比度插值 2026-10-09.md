# FNO固定几何对比度插值

承接 [[单参数优化与自由像素对照 2026-10-09]]，执行已保存的局部材料族协议。此前 [[普通FNO十二材料单源训练与验证 2026-10-08]] 的新材料散射误差很高；本轮固定几何和源，去掉位置、尺寸和形状变化，只检查材料对比度插值。

> [!summary] 结果与决策
> 固定1200次，训练散射场／接收误差38.86%／11.23%，两中间对比度插值33.09%／10.43%。模型优于零散射，接收优于训练均值和最近邻，但全场仍欠拟合，且线性物理插值仅5.91%／5.62%，明显更好。
> 当前不能宣称FNO优于简单参照或已具备反演能力。下一轮只把width4改为width8，复用完全相同的冻结数据和1200更新；协议已保存，尚未运行。不扩展几何或同时改损失、频带和输入。

## 协议和范围

只用原训练工件000的合成几何，取 $D=\{\gamma_{000}<0.99\}$，449个物理单元。支撑内统一为a，外部为1。该工件为既有训练来源，未读取旧验证或测试材料。

- 训练对比度：0.3、0.5、0.7。
- 开发插值对比度：0.4、0.6。
- 只用原源0，同一24接收坐标，2000步、30ns、500物理波场帧。
- 保持普通BasicFNO：8输入、后两通道为0，width4、4层、modes(16,8,64)、padding0，seed2；初始权重哈希与旧十二材料阶段一致。
- Adam lr0.001，旧场／接收尺度，场与接收监督权重1；依次循环三材料，共1200更新，每件400次。
- 固定0／400／800／1200评价，最终1200为主结果，中间指标不用于早停。

训练与开发有意共享几何，只有材料值不同。这是一个受控一维插值任务，**不是新几何或独立工件泛化**。也不能把本轮与旧六材料验证的差异全归因于数据覆盖：任务复杂度、材料和训练预算均不同。

## 数据与物理参照

在训练前保存协议与来源哈希；用同一作者离散正演生成五个材料的完整接收及500帧。所有稀疏接收逐值等于波场采样。重新计算的无缺陷源0场和接收与旧homogeneous.pt逐值一致。

目标为 $\delta u(a)=F(\gamma_a)-F(1)$，基底冻结；旧训练RMS继续使用：场0.15921596709548344、接收0.25594272720229144，不利用新开发标签重算尺度。

四种参照均不在开发真值上拟合系数：

| 参照 | 定义 |
| --- | --- |
| 零散射 | 直接返回固定无缺陷基底 |
| 冻结训练均值 | 三个训练散射目标的均值 |
| 对比度最近邻 | 使用最近训练材料的散射场；距离相同时选较小a |
| 分段线性插值 | 已知输入a，仅组合相邻两个训练物理解 |

例如a=0.4使用0.3／0.5各一半，a=0.6使用0.5／0.7各一半。它直接缓存训练物理场，在这个一维已知材料族上合法且很强；不能自动外推为未知几何的求解器。参照的接收也从500帧按同一三次时间重建评价，避免给参照和网络不同的时间处理。

## 固定最终结果

相对L2先合并误差和真值能量再开方；完整场／波形分母包含固定背景能量，散射分母只含材料变化。完整接收评价2000步，场评价500帧。

| 固定1200指标 | 三训练材料 | 两开发插值材料 |
| --- | ---: | ---: |
| 平均场监督MSE | 0.02162046 | 0.01364569 |
| 平均接收监督MSE | 0.00160572 | 0.00123270 |
| 散射场相对L2 | 38.857% | 33.088% |
| 散射接收相对L2 | 11.228% | 10.435% |
| 完整场相对L2 | 14.671% | 11.665% |
| 完整接收相对L2 | 4.012% | 3.517% |

完整接收3.52%不能替代散射接收10.43%，也不能忽略散射场33.09%。开发合并误差较训练低，不证明开发比训练更难或性能普遍更好；对比度范围和目标能量不同。

### 简单参照比较

| 方法 | 训练散射场／接收 | 开发散射场／接收 |
| --- | --- | --- |
| FNO | 38.857%／11.228% | 33.088%／10.435% |
| 零散射 | 100%／100% | 100%／100% |
| 冻结训练均值 | 42.846%／41.471% | 29.033%／28.015% |
| 最近邻 | 0%／0.05273% | 32.706%／30.943% |
| 分段线性 | 0%／0.05273% | 5.913%／5.620% |

训练最近邻／线性在场上直接返回缓存训练目标，所以场误差0；接收约0.05273%来自稀疏场重建到完整时间轴，不是拟合错误。开发线性参照没有用开发波形求系数，不属于真值oracle波形拟合。

FNO接收优于均值及最近邻，但其开发全场甚至略差于这两个参照，并明显落后于线性插值。因而本轮是“取得局部拟合改善但没有优势”的结果，不能据此宣称神经网络必要或有加速收益。
