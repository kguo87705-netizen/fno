# 普通FNO散射目标多工件验证

本轮完成普通 FNO 的散射残差多工件训练，固定 20 epoch、960 次更新。完整场指标优于旧直接全场模型，但基本只是无缺陷基底的水平；验证散射误差没有优于零散射预测，材料差分仍很弱。不能将单样本 1.98% 完整接收误差推到未见工件。

承接 [[普通FNO散射残差目标单样本对照 2026-10-08]]；匹配的旧直接目标对照见 [[普通FNO多工件同预算对照与材料响应 2026-10-08]]；主计划见 [[FNO与超声全波形反演科研计划 2026-10-07]]。

## 固定对照与执行

同一 12/6 个训练/验证工件、48/24 次发射；旧测试不加载。模型、seed=2 的初始权重哈希、全部 20 轮样本顺序、Adam lr=0.001、接收权重 1、原全波场/接收 RMS 都与旧直接目标组匹配。唯一主要改变是网络目标 `FD(gamma)−FD(1)` 和相应固定无缺陷基底还原，不增加输入特征或物理残差损失。

开始前保存新协议，主比较为固定最终第 20 轮，不按验证结果挑选模型。每轮完整接收用完整无缺陷波形加重建残差；波场用无缺陷快照加预测残差。固定基底只适用于当前材料背景、激励和阵列，改变这些条件需另行获得对应基底。它的计算成本仍应纳入未来成本比较，本轮没有加速结论。

## 最终训练与验证

相对 L2 先合并误差和真值平方能量再开方。

| 验证指标 | 无缺陷/零散射 | 直接全场＋接收 | 散射目标＋接收 |
| --- | ---: | ---: | ---: |
| 完整波场相对 L2 | 28.35% | 85.54% | 28.39% |
| 完整接收相对 L2 | 24.85% | 55.85% | 24.90% |
| 散射波场相对 L2 | 100.00% | 301.68% | 100.13% |
| 散射接收相对 L2 | 100.00% | 224.71% | 100.17% |

| 散射目标组指标 | 训练工件 | 验证工件 |
| --- | ---: | ---: |
| 完整波场相对 L2 | 30.59% | 28.39% |
| 完整接收相对 L2 | 26.05% | 24.90% |
| 散射波场相对 L2 | 99.95% | 100.13% |
| 散射接收相对 L2 | 98.18% | 100.17% |

训练散射接收误差也接近零预测水平，当前不是训练目标已充分拟合、仅验证失败。与旧直接目标组相比，总场变好主要体现为固定基底提供了共性波形；这不等于模型学到有效散射。第 20 轮验证略差于零散射，但不能把这一很小差距解释为统计显著：只运行了一个种子，没有独立重复或置信区间。

此前中间轮散射接收误差曾略低于 1。本轮保留预先指定的最终轮主比较，不用中间轮的微小改善替代最终结果；20 轮也不构成训练收敛证明。

## 材料差分审计

冻结最终模型，比较总预测在 gamma 与均匀材料 1 下的差分，与 `FD(gamma)−FD(1)` 比较。散射模型的固定基底在两种输入的总预测相减时抵消，因此可以直接比较网络残差输出的差。均匀材料不是训练工件，属于诊断反事实。

| 验证差分响应指标 | 旧直接目标组 | 散射目标组 |
| --- | ---: | ---: |
| 差分响应相对 L2（零响应=1） | 1.00390 | 1.00009 |
| 预测/参考差分范数 | 7.92% | 0.86% |
| 差分余弦 | -0.00967 | -0.00565 |

材料差分范数仅为参考约 0.86%，方向近乎正交。该诊断显示当前网络输出对材料变化的响应不足；它不是局部物理梯度或伴随检查。本轮未进行新的 FWI、物理梯度或独立测试评价。

## 下一步：只检查时间Fourier输入表示

可检验假设：目前材料图和缓慢时间坐标输入，在窄通道和固定预算下不易生成材料相关的振荡响应。原有时间谱模态覆盖主要真值能量，并不保证网络已经学好该频段。这个解释尚未通过因果对照；也可能存在容量、预算或归一化影响，本轮不同时改这些因素。

下一轮设置两个**同样八输入通道**的普通 FNO：前六通道保持原值，另两通道在对照组恒为 0，在实验组为 `sin(2π×0.5MHz×t)` 和 `cos(2π×0.5MHz×t)`。频率取公开固定激励，不由验证成绩调选。两组初始权重哈希一致，宽度、层数、模态、散射目标、基底、旧尺度、接收权重 1、数据划分、样本顺序与训练预算均一致；各固定 20 轮，主要比较最终轮。

不能直接把八通道实验与旧六通道结果归因比较：提升层形状与随机数消耗改变，需新增八通道零特征组作为对照。主要报告验证散射波场、散射接收、完整场及材料差分，继续保留零散射基准。若仅总场改善、差分仍弱，依然不进入代理反演。该输入特征对照尚未运行，协议已保存为 `.build/basic-fno-scatter-multi-20261008/next_time_features_protocol.json`，标为 planned_not_run。

方法候选依据是 [Tancik 等 Fourier Features 原论文](https://arxiv.org/abs/2006.10739)：其研究对象为 MLP 高频低维回归，不能直接保证本 FNO 的效果。此前核对的 [Kong 等频域 FNO 频率偏置工作](https://arxiv.org/abs/2503.02023v2) 也与当前时域任务不同。这里借用输入表示的可检验思路，不将当前失败直接归因于频率偏置。
