# 最小实验设计

这是可执行前的实验方案，不是已经跑过的论文复现。先用小问题验证理解，再迁移到导波。

## 实验A：单个解函数与算子

用一维常波速方程 $u_{tt}=c^2u_{xx}$，区间0到1，两端零位移，初位移 $\sin(\pi x)$、初速度0。解析解为 $u(x,t;c)=\sin(\pi x)\cos(\pi ct)$。

- 固定一个 $c$：坐标网络近似一个解。
- 多个 $c$：把 $c$ 作为条件输入，观察跨参数预测。这个条件网络练习本身不能当作完整FNO复现。
- 使用未训练的 $c$、独立时空点计算误差；分开记录插值与外推。
- 先用解析式检查初边值与方程残差，排除生成器错误。

## 实验B：Fourier特征与优化

拟合 $f(x)=\sin(2\pi x)+0.2\sin(20\pi x)$，比较普通MLP与Fourier特征MLP。保持训练点、参数规模、优化步数及多个随机种子可比。

记录总误差、两个频率分量的误差与训练曲线；不要把这个函数拟合结果宣称为超声成像验证。

## 实验C：论文级消融计划

从P05或P09获取数据与方法后设计四组：基线、有物理约束、有精修／改进模块、二者都有。相同试件划分、预算、源与边界条件。

| 项目 | 开始运行前必须确定 |
| --- | --- |
| 数据 | 生成器版本、材料、激励、网格、独立几何划分 |
| 标签 | 物理量、单位、归一化及反归一化 |
| 方程 | 边界、离散算子与适用条件 |
| 指标 | 全域、缺陷区域、物理残差、独立实测 |
| 复现 | 代码版本、配置、种子、硬件、训练与推理分别计时 |

完成A或B只是概念实践。要将C标为复现完成，需对照原文关键图表且解释差异。
