# 原始目标重评与两周研究决策

当前暂停扩展神经模型和主动测量框架。优先确认有意义的反演任务能否被可信的简单方法解决，以及它究竟贵在哪里。现有证据尚未证明神经方法具有稳定的反演质量或总成本优势；这不等于否定神经算子。

本次判断承接 [[FNO超声FWI原计划 2026-09-27]]：神经算子能否改善超声 FWI 的计算效率或反演效果。主动选发射、极小材料差异分类、亚网格表示和界面离散只有能服务这一目标，才继续扩展。本次决策覆盖总计划中的历史“下一步”；已有实验结果与失败记录完整保留，不把完成实验数量当作科研进度。

## 真正减少不确定性的实验

| 实验 | 得到的认识 | 结论边界 |
|---|---|---|
| 发布观测与求解器自洽观测对照 | 自洽观测下，最终目标函数降至初始的10.75%，材料误差仍增至2.03倍。观测失配不能独自解释失败 | 尚未分离高维自由度、约束、正则化和优化路径 |
| 匹配初始化与训练次数的材料回放 | 材料响应误差由30.30%降至6.81%，对照34.79%。覆盖确实影响局部响应 | 未证明未知几何恢复、全场精度或实际加速 |
| Adam状态、接收损失、低频损失对照 | 重置Adam无明显改善；去掉接收损失破坏响应；低频损失未产生预期改善 | 只削弱这些具体解释，不能排除一般优化问题 |
| 固定预算物理修正与神经初始化比较 | 神经初始化未显示稳定的最终质量或成本优势，简单插值加物理修正有竞争力 | 开发样例上的更低误差不等于整体加速 |
| 未知幅度物理基线 | 合成共同增益变化可使错误率达49.55%；有界增益拟合后最坏约0.9% | 仅为四状态合成问题，未验证真实仪器失配 |
| 网格别名与解析界面 | 连续坐标可能映射成相同材料输入；四倍细化二值表示波形误差约4.05%，位移差分误差仍约536% | 未证明真实声学不可辨识，也未验证二维精细定位 |
| 观测驱动第二源 | 固定双源误判0.975%，自适应0.825%，收益尚不确定 | 4000次噪声试验只有四种工件状态；绝对改善门槛在该低错误率基线上不可达到，不能只凭门槛判定科学失败 |

精度设置、状态复用、接口、保存重载、成本台账和日志修复是必要基础设施。面积守恒与独立积分证明几何模块计算正确，不证明声学前向或反演可信。宽度、轮数与开发集损失的改善，只有在独立任务质量和完整成本上兑现，才构成原始目标的进展。

## 六类瓶颈的证据强弱

| 瓶颈 | 当前证据 | 最强替代解释或限制 |
|---|---|---|
| 物理与观测不一致 | 当前复现链条与合成增益实验中证据强；真实设备层面未知。原真值前向与发布观测相差约51.55% | 可来自离散、源或生成流程；自洽观测仍失败，失配不是唯一原因 |
| 可辨识性不足 | 表示别名已证实；实际声学可辨识性证据不足，有限方向分析提示敏感度不均衡 | 弱响应依赖参数化；六个方向不能代表完整Jacobian |
| 数据覆盖不足 | 局部因果证据较强；作为全局主因证据不足 | 回放未同时解决全场误差和任务泛化，不能据此无限扩充数据 |
| 代理误差 | 当前FNO的局部响应、偏移几何与反演偏差问题证据强 | 结论限于已测模型与分布，不否定所有神经算子 |
| 优化问题 | 反演失败证据强，具体优化归因未确定 | 残差下降而材料变差也可来自自由度、约束或目标函数；Adam状态对照只检验一个解释 |
| 评价设计问题 | 证据强，优先修复 | 同字典生成识别、重复开发样例、噪声伪重复、成本漏项和指标错位限制结论 |

目前最有解释力的工作假说：任务定义、观测模型和数值误差尚未充分隔离，代理又引入额外偏差。模型容量不足不是已确认的首要原因。

## 简单基线与神经方法的价值要求

- 已知几何、单材料参数：物理一维搜索、局部插值或割线，再做物理核验。物理细网格能找回已有测试真值；固定八步物理修正后神经初始化没有稳定优势。
- 当前四状态、未知幅度：固定双源加有界增益拟合，最坏错误率约0.9%。它使用包含全部真值的精确字典，不能代表盲反演。
- 未知位置与材料：最强简单基线的能力仍未充分建立，这是核心缺口。

现有同质量成本复核没有建立总成本优势，完整离线成本和回本工件数未知。神经方法应在独立工件、相同观测预算和明确质量约束下减少完整反演成本，计入数据生成、训练、物理核验、失败回退与重放。减少实际发射次数作为另一研究问题暂缓，不与本轮加速证明捆绑。

## 方向取舍与保留成果

继续物理参考、未知参数任务的简单基线、工件级独立评价、观测干扰建模和完整成本记录。暂缓新架构、扩大训练集、DeepONet全面铺开、主动采集、不确定性模块及PINN或展开网络组合；只有发现明确且可被其解决的基线瓶颈才恢复。

停止围绕同一小批样例反复调整损失与训练量、将灵敏度改善当作反演改善、默认继续亚网格定位链条、为维护原计划增加组件。

保留求解器与梯度检查、数据和哈希清单、物理插值及增益拟合基线、解析界面基准、几何模块、失败样例与因果对照。几何模块仅保留已核验的几何用途。上述成果支持可复现记录，是否构成论文创新另行判断。

## 两周内最多两项任务

### 任务一 建立可信且值得加速的反演任务

期限：2026-10-12至2026-10-16。

限定二维单缺陷，未知中心与材料参数，形状先固定，明确属于受限参数反演。采用物理粗搜索或局部插值加增益拟合。观测参考使用经过收敛检查的更细网格，避免同一粗网格字典识别自身。开发工件与封存测试工件按几何划分。

验收：测试前冻结位置与材料误差容限及失败定义，容限来自检测需求或明确研究用途；数值参考误差对目标量的影响不超过容限四分之一；停止和回退只使用可观测量，真值仅作事后评分；给出完整成本，并确定是否存在足够大的计算瓶颈。

转向：第5天仍无法建立可信参考或有意义容限，则暂缓神经加速，收缩为物理基线与误差边界研究；简单方法已经满足质量和成本需求，也不添加神经模型。不强制追求亚网格精度。

### 任务二 有条件地挑战同质量总成本

期限：2026-10-17至2026-10-25。

仅在任务一证明基线可信但昂贵，且现有代理适用时启动。冻结一个现有神经候选，与最强简单基线比较；不增加架构，不根据封存测试结果再训练。

验收：测试前明确质量非劣容限，检查独立工件样本量能否支撑判断；质量通过后，完整成本至少降低20%，配对不确定性分析支持收益为正；计入离线成本后，在预先声明的实际使用规模内能够回本。20%是事先提出的投入门槛，不是已有结果。

转向：质量不达标、收益不确定、回本规模不现实或现有代理不适用，就停止当前神经路线投入并归档。任务一不通过时，第二项仅整理失败边界和路线决策，不另开模型实验补救。

两周阶段性产出是恢复神经加速还是冻结当前路线的投入判断，不承诺正面结果或论文进度。
