# 传统FWI观测一致性与材料响应复核

本轮承接 [[传统FWI近真值与均匀初值诊断 2026-10-08]]，先核查作者案例1的真值正演与发布观测，再用保持密度为正的六个材料方向计算接收响应与Gram矩阵。主要发现是：真值在当前发布源、材料和正演设置下与发布观测相差51.55%，此前将小绝对代价解释成残差接近零不成立。下一步应先追查数据生成设置并建立自洽反演对照。

## 观测一致性和真值梯度对照

同一4源、24接收、2000步、30ns设置，双精度提升原系数值；作者原正演与离散参考在真值上逐值一致，排除了本轮函数式正演改写引起这一差异。

发布观测组一步代价降至1.6607471e−12，同时偏离真值；自洽组仅有上下界处理的舍入量变化。自洽组证明在这一个真值状态的实现闭环，尚未证明均匀或近真值初始的完整反演成功。已有发布观测反演的材料恶化不能先归因于不适定性或学习率；数据／模型一致性是更早的待解决因素。

## 六方向接收响应和Gram矩阵

方向为浅层、深层、左侧、右侧高斯区域、缺陷内部相对对比度和全域相对变化。高斯标准差8mm，浅／深中心分别为(50,40)mm与(50,10)mm；阵列在y=50mm。全部屏蔽ghost及源接收材料。

定义d=gamma×峰值归一化区域函数，缺陷区域为gamma<0.5。用epsilon=1e−4和5e−5计算未投影的双侧波形响应Jd≈[F(gamma+epsilon d)−F(gamma−epsilon d)]/(2epsilon)。密度保持正；正侧可能超过优化上界1，属于内部函数导数检查。各方向参数是相对材料变化，不与上轮L2归一化的绝对材料扰动直接比较。

| 方向 | ||Jd||／||发布观测||，每单位相对参数 |
| --- | ---: |
| 浅层 | 0.194936 |
| 深层 | 0.096835 |
| 左侧 | 0.142497 |
| 右侧 | 0.131416 |
| 缺陷内部对比度 | 0.000029142 |
| 全域 | 0.769690 |

两幅度响应差异均低于2.4e−6。六方向归一化波形响应的非对角相关性最大约0.445；单位响应矩阵奇异值为1.2103、1.0984、1.0137、0.9763、0.9044、0.7282，没有在这六维子空间观察到严重线性相关。原始响应奇异值跨度较大，主要与方向响应强弱不同有关。缺陷gamma约1e−5，相对密度方向对应的绝对扰动极小；弱响应不能自动推广到缺陷尺寸或位置不可恢复。

另将正向相对步epsilon=0.005投影到优化可行域：背景gamma=1的正向步被裁掉，大多数实际扰动仅发生在缺陷内部，最大实际步约1e−11至5e−8。这种投影后的小代价变化不能证明未投影方向“普遍平坦”，也不是沿负梯度的回溯接受实验。

## 上轮解释的修正与下一步

上轮原始有限步数字保留，但应撤回“残差接近零”“中心差分说明普遍平坦”的解释：投影正负步不对称；L2归一化令实际单元变化很小；代价尺度被误当作相对残差；近空洞单元不允许随意施加绝对双侧扰动。

本轮最早的绝对方向双侧试运行触发负密度和非有限波形，未形成有效报告；修正为上述双精度相对方向后完成。旧失败目录只含协议，不能作为实验成功记录。

下一轮先固定作者案例1，追查发布数据的生成脚本／网格／源及材料边界设置；保持发布数据作为独立问题记录，同时用同一正演生成观测，固定统一预算比较均匀和近真值初始。先验收自洽反演与材料恢复，再决定是否研究单一参数化或正则化改进。FNO训练数据来自当前自生成正演，这一发现不直接推翻FNO训练结果；材料泛化仍需独立解决。
