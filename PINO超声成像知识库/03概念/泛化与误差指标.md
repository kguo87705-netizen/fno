# 泛化与误差指标

先确定测试变化的是时间、介质、频率、网格还是设备，再谈泛化。

## 最小知识

| 检查对象 | 应问的问题 |
| --- | --- |
| 相对 L2 | 是否为 $\|u-\hat u\|_2/\|u\|_2$？接近零的参考值如何处理？ |
| RMSE | 单位是什么，是否在归一化空间计算？ |
| SSIM | 看结构相似，但是否也检查物理参数偏差？ |
| 缺陷区域误差 | 区域如何定义，是否被背景平均掩盖？ |
| 推理时间 | 硬件、批量与输入规模是否相同？ |

按独立几何或试件划分，避免同一试件的相邻快照进入训练和测试。噪声测试、跨频率测试和实测验证是不同证据。

## 检验理解

随机拆分同一仿真序列的帧能证明跨缺陷泛化吗？

> [!tip]- 回答后展开
> 不能；相同几何及相近波场可能造成泄漏。
