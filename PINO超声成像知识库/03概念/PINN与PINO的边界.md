# PINN与PINO的边界

用训练对象和物理约束位置分类，比按方法名分类可靠。

## 最小知识

| 类型 | 常见训练对象 | 物理约束 |
| --- | --- | --- |
| 坐标 PINN | 给定问题的解函数 $u_\theta(x,t)$ | PDE、初边值或数据损失 |
| Fourier特征 PINN | 经过坐标特征编码的解函数 | 仍可采用 PINN 损失 |
| FNO | 一族输入函数到输出函数的算子 | 可纯监督，也可加入约束 |
| PINO | 带物理约束的算子学习框架 | 原始工作结合数据与 PDE，可跨分辨率施约束 |
| 物理增强 U-Net | 常见为网格上的输入输出映射 | 可用离散方程残差 |

此表描述典型范式；存在参数化 PINN 等变体。P01 不能仅凭 U-FNO 名称归为 PINO。P05/P06 可与 PINO 思路对照，但严格实现关系仍须读方法。见 [[B02 PINO基础论文]]。

## 检验理解

使用模拟数据训练算子是否自动等于物理信息算子？

> [!tip]- 回答后展开
> 不等于；模拟数据提供数据来源，显式物理约束是另一个维度。
