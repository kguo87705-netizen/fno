## 1 一眼看懂：FWI 在干什么

### 1.1 三层递进

**第一层 —— 正演与反演的分界**

$$u=\mathcal G(m;\,s,b),\qquad d=\mathcal P u+\epsilon$$

- $m$：**介质参数**（本项目里是密度缩放场 $\gamma$）
- $s$：激励源；$b$：边界条件；$\mathcal P$：接收采样算子
- $\mathcal P$：把"整片波场"变成"阵列上采到的信号"

已知 $m,s,b$ 求 $u$ → **正演**；由观测 $d$ 反求 $m$ → **反演**。

**第二层 —— 反演写成一个优化问题**

$$\min_{m}\ \underbrace{\|\mathcal P\mathcal G(m)-d_{\rm obs}\|^2}_{J(m)}+\lambda R(m)$$

**第三层 —— 为什么它慢（本项目要加速的那个"慢"）**

每一次迭代都要做两件事：

1. **正演** $\mathcal G(m)$：时域有限差分推进 $N_t=2000$ 步；
2. **求梯度** $\nabla J$：需要 **伴随（adjoint）**，即再解一次"反向传播的波场"。

> 🔴 **成本事实**：一次 FWI 迭代 ≈ **2 次波场模拟**（1 次正演 + 1 次伴随）。
> 作者四案例我一例跑了 35 次更新 → 约 **70 次波场模拟**。这就是"神经算子加速"想切进去的入口。

### 1.2 与 TFM 的区别（不是"哪个图更清楚"）

| | TFM（全聚焦法） | FWI |
| --- | --- | --- |
| 做什么 | 按走时**延时叠加**，出成像强度 | 迭代匹配**完整波形**，出定量材料参数 |
| 用了哪些信息 | 主要用**走时** | 走时 **+ 振幅 + 相位 + 散射/绕射** |
| 声速 | 需要**预设** | 声速/密度是**未知量** |
| 输出物理量 | 反射强度（相对量） | 材料参数（绝对量） |

$\Rightarrow$ **TFM 的亮点图与 FWI 的 $\gamma$ 图不是同一物理量，不能只比较"哪张更好看"。** 见 [[FMC与TFM]]。

## 2 拆词：这七个字每个都是信息

| 词 | 英文 | 含义 | 本项目的值 |
| --- | --- | --- | --- |
| **FWI** | Full Waveform Inversion | 迭代调材料参数、让模拟波形贴近实测波形 | 反演 $\gamma$ |
| **超声** | ultrasound | MHz 级弹性波的**无损检测**（NDT），不是地震的 Hz 级 | **500 kHz** |
| **相控阵** | PAUT, Phased Array Ultrasonic Testing | 多个小阵元，靠发射延时"电控"波束方向与聚焦 | 单侧线阵 |
| **有限孔径** | limited aperture | 发射与接收只覆盖**有限的角度范围** | **同一侧 4 发射 / 24 接收** |

**FMC 与 TFM 的形式（教学示意，见 [[FMC与TFM]]）**

- FMC（Full Matrix Capture，全矩阵捕获）张量 $d_{ij}(t)$：第 $i$ 个阵元发射、第 $j$ 个阵元接收；
- TFM 成像 $I(\mathbf r)=\sum_{i,j}d_{ij}\bigl(\tau_i(\mathbf r)+\tau_j(\mathbf r)\bigr)$。

> 🔴 **本项目口径**：作者论文**自己**把该设置描述为"**受 PAUT/FMC 启发**"，实际只用了 **4 次发射**。
> 所以在本库任何地方都**不能**写成"我们复现了完整 FMC"。

2. **代码有解、数据有解** —— 这是最硬的约束（另两个候选连可运行性都没核实）；
3. **二维标量波是简化平台**，适合**先验证计算方法**，把弹性、实测、仪器响应留到后面加。

> 这**不是**金属弹性波真实 FMC 的终点。与金属相控阵相关的实验结论，必须等**弹性正演、真实源响应与采集数据**验证后才能说。

### 3.3 为什么 M0 值得花力气：假胜利的两个来源

$$\text{要证明"神经算子能加速 FWI"} \Rightarrow \text{必须有一个"值得被加速"的传统 FWI} \Rightarrow \text{传统 FWI 本身必须可信}$$

如果参照本身不可信，会出现两种**假胜利**：

| 假胜利 | 机制 |
| --- | --- |
| **假加速** | "加速"的其实是**一个本来就算错的**正演；替代掉错误计算当然更快 |
| **假精度** | 代理的误差被参照的误差**掩盖**，看起来更准 |

所以 M0 的目标不是"跑通"，而是建立**可公平比较的参照**：

| 比较维度 | 要求 |
| --- | --- |
| 任务 | 相同的 $\gamma$、源、接收几何 |
| 数据 | 相同划分（按**独立工件/介质实例**，不是按帧） |
| 指标 | 相同定义（波形相对 L2、材料半 MSE、梯度夹角） |
| 成本 | 相同口径（数据生成 / 训练 / 每次正演 / 每次反演 / 校正） |
| 精度 | 相同硬件与数值精度 |

> 后面你会看到：连 `float32` 的 **TF32 开关**都会污染结果（第 9.3 节）。可见"可公平比较"有多难。

## 4 物理模型与参数表

### 4.1 控制方程（原文证据）

二维**标量**波，未知量为**无量纲密度缩放场** $\gamma$，**背景波速固定**：

$$\gamma\rho_0\,\partial_{tt}u-\nabla\cdot\bigl[\gamma\rho_0c_0^2\nabla u\bigr]=f_s(x,t)$$

- $\rho_0=2700\ \mathrm{kg/m^3}$、$c_0=6000\ \mathrm{m/s}$ **保持固定**
- 缺陷由**小 $\gamma$** 表示（近空洞 $\gamma\sim10^{-5}$）
- 背景 $\gamma=1$

> 🔴 **重建图不是纵波声速图**：因为 $c_0$ 固定、只有 $\gamma$ 在变。因此**不能**与 [[P01 U-FNO超声全波形直接反演]] 输出的纵波声速场逐像素比较。

### 4.2 参数表（含来源）

| 量 | 值 | 来源 |
| --- | --- | --- |
| 域尺寸 | $0.10\times0.05$ m | 论文 |
| 激励 | 两周期 **500 kHz** | 论文 |
| 反演网格 | $N_x=255,\ N_y=127$（材料数组 256×128） | `settings2D.csv` |
| 时间 | $dt=3\times10^{-8}$ s，$N_t=2000$（总 60 μs） | `settings2D.csv` |
| $\gamma_{\min}$ | $10^{-5}$（近空洞） | `settings2D.csv` |
| 源 | **4 个，与接收点在同一侧边界** | 代码 |
| 接收 | 间隔 6 个网格索引 → 算出 **24 个接收点** | `Utilities.py` + 设置表 |
| 论文参考数据网格 | **512×256**（反演故意用不同网格以减轻 inverse crime） | 论文 |

**本机执行后核对（实验事实）**

- 材料数组 256×128，**含 ghost cells 为 258×130**；
- 残差张量实际 shape `[1, 4, 24, 2000]`；
- ⚠️ **原代价沿 `axis=2` 积分 → 落在"接收"维而不是"时间"维**；已另存"正确时间积分"评价，**未改动原始优化轨迹**；
- ⚠️ 论文第 2.2 节写反演为 1000 步 × 60 ns：**总时长一致但时间离散不同** → 待对齐。

## 5 正演：一次要花多少算力

```
输入：材料场 γ（256×128，含 ghost 258×130）、源 f_s、边界条件
重复 t = 0 … 1999：
    用有限差分近似 ∇·(γρ₀c₀²∇u) 与 ∂_tt u
    推进一个时间步 → u[:, :, t+1]
输出：波场 u（4 源 × 258 × 130 × 2000）→ 采样成 d（4 × 24 × 2000）
```

**四个数值细节，每个都能改变结论**

1. **ghost cells**：边界处理的缓冲层，`Nx+3`/`Ny+3` **不等于**物理域采样数；
2. **时间步与稳定性**：$dt$ 必须满足 CFL 类条件，否则数值发散；
3. **边界条件**：吸收/自由表面选错会制造**假反射**，污染晚期波形；
4. **单位与量纲**：源力、位移、$dt$、密度、波速必须逐项核对，**不在不同量纲的波形上直接比较 MSE**。

## 6 反演：数学与算法

### 6.1 记号

令 $\mathcal G(m)$ 包含**波场求解 + 接收采样**，$d_{\rm obs}$ 为观测：

$$r(m)=\mathcal G(m)-d_{\rm obs},\qquad J(m)=\tfrac12 r(m)^T W r(m)$$

$$\nabla J(m)=D\mathcal G(m)^T W\,r(m)$$

- $W$：时间积分等固定权重
- $D\mathcal G(m)$：**材料 Jacobian** —— 描述"材料怎么变 → 波形怎么变"

⚠️ **两个东西共同决定更新方向**：① 波形预测值（决定 $r$）；② 材料 Jacobian $D\mathcal G$。
**它们可以一个对一个错。** 这是本页第 9 节的主线。

### 6.2 算法步骤

```
输入：初始材料 γ⁰（如全 1）、源子波、观测 d_obs
重复 k = 0,1,2,…：
  1 正演:  uᵏ = G(γᵏ)                         # 2000 步 FD
  2 采样:  dᵏ = P uᵏ                           # 4×24 点 × 2000 时刻
  3 残差:  r  = dᵏ − d_obs
  4 伴随:  解一次伴随方程 → ∂J/∂γ               # 成本 ≈ 又一次正演
  5 更新:  γᵏ⁺¹ = clip(γᵏ − α·∂J/∂γ, γ_min, γ_max)   # Adam, α=0.02
  6 记录:  J、材料误差、模型历史
直到迭代用尽或满足停止规则
```

### 6.3 连续伴随 vs 离散自动微分

- **连续伴随**：先在 PDE 层推导，再离散；
- **离散 AD（自动微分）**：先固定实际数值程序，**对该程序**求导。

边界、系数平均、接收采样、时间积分处理不匹配时，两者**可以不同**。

**本项目的实测（实验事实，[[作者传统FWI四案例运行与梯度审计 2026-10-08]]）**：案例 1 原伴随与离散参考梯度的夹角在初始／第 5 次更新约 **39.47°／42.14°**，差异能量集中在**阵列侧边界附近**。

> ⚠️ 这支持"先采用离散参考作诊断基准"，但**不能**推广为"所有伴随方法都有错误"，也**不能**把一次差分通过等同于物理建模全部正确。

**导数检查应比较同一掩膜与同一内积下的量**

$$\nabla J(m)^Tv\approx\frac{J(m+\epsilon v)-J(m-\epsilon v)}{2\epsilon},\qquad D\mathcal G(m)v\approx\frac{\mathcal G(m+\epsilon v)-\mathcal G(m-\epsilon v)}{2\epsilon}$$

需要**多档 $\epsilon$**，寻找"截断误差—舍入误差"之间的稳定区间。**不能跨过非正密度**；若两侧被可行域投影，必须报告**实际扰动**，而不能仍按未投影的中心差分解释。

## 7 为什么"有限孔径"是问题的物理根源

### 7.1 配置对比

|      | 全环 / 双侧孔径      | **单侧有限孔径（本项目）**           |
| ---- | -------------- | ------------------------- |
| 例子   | 医学环阵层析、水浸上下双阵列 | 表面接触式/水浸线阵，**4 发射 24 接收** |
| 照明角度 | 多方向穿过目标        | 只能从一个扇面射入、再反射回来           |
| 反演约束 | 强              | **弱**                     |
| 主导波型 | 透射             | **反射**                    |

### 7.2 三个后果（都是实测，不是推测）

**后果 1 — 弱响应：某些材料变化产生的信号极弱，梯度接近零，那个方向就不动**

案例 1 真值附近，相对材料方向的响应范数 ÷ 发布观测范数：

| 方向 | 响应范数比 |
| --- | ---: |
| 浅层 | 0.194936 |
| 深层 | 0.096835 |
| 左侧 | 0.142497 |
| 右侧 | 0.131416 |
| **缺陷内部** | **约 $2.9142\times10^{-5}$** |
| 全域 | 0.769690 |

（[[相控阵FWI与神经算子阶段总结及知识梳理 2026-10-08]] 第 6.3 节，**实验事实**）

**后果 2 — 方向混淆：不同材料变化给出近似相同的波形**

归一化响应的**最大非对角相关 ≈ 0.445**；六个奇异值 ≈ **1.210 / 1.098 / 1.014 / 0.976 / 0.904 / 0.728**。

$\Rightarrow$ 所选方向之间**没有显著的近线性依赖**，但**信息确实有限**。

**后果 3 — 更多迭代没用**

$\nabla J$ 只能利用**已经采到的信息**；优化器**不能生成缺失的采集角度**。

### 7.3 但**不能**直接说"不可辨识"

> [!danger] 这是最容易说错的一句
> 看到重建失败就断言"不可辨识"是**跳步**。必须先依次排除：**损失实现 → 求导 → 观测模型 → 优化设置**，再检查"不同材料是否给出近似相同波形"。
> 而且上面那组六方向数字只是**选定的六个方向**构成的**局部**证据，**不能**证明整个像素空间的唯一性。
> 缺陷的 $\gamma$ 本来极小（$10^{-5}$），相对扰动对应的**绝对**变化也极小，所以**不能**由此断言缺陷形状/尺寸/位置不可恢复。

**这就是为什么本项目要建"证据阶梯"（第 9 节）。**

## 8 具体例子：为什么细节会致命

### 例 1（孔径 → 代价面的"山谷"）

表面只从一个角度打波。一个**浅、小**的缺陷与一个**深、大**的缺陷可能返回**几乎相同**的接收波形 → 代价面上出现一条"山谷" → 优化滑到错误的解。

**现象**：代价下降（拟合好了），材料距离却变大。

**本项目实测**（[[作者生成网格与自洽反演对照 2026-10-08]]，**实验事实**）：

| 观测／初始 | 波形相对 L2（初始→最终） | 最终／初始代价 | 最终／初始材料半 MSE |
| --- | ---: | ---: | ---: |
| 发布／均匀 | 74.29% → 47.78% | 0.4136 | **2.0796** |
| 发布／近真值 | 51.67% → 42.15% | 0.6655 | **253.57** |
| 自洽／均匀 | 56.34% → **18.48%** | **0.1075** | **2.0296** |
| 自洽／近真值 | 8.17% → 3.08% | 0.1418 | 7.0467 |

即使用**自洽观测**（观测由同一个正演生成），代价降到初始的 **0.1075 倍**，材料误差**仍升到 2.03 倍**。

### 例 2（损失轴 → 目标函数被换掉）

残差 shape `[1, 4, 24, 2000]`。

- 沿 `axis=2`（**接收维**，长度 24）积分 → 相当于只在"通道"上凑总数，"总能量"对了但**相位/时间错位不被惩罚**；
- 沿**时间维**用 `trapz` 积分，才是物理上的波形失配能量。

$\Rightarrow$ **一个轴选错，整个反演的目标函数就变了。** 本项目发现并修正了这一点（另存正确时间积分评价，未改原轨迹）。

## 9 波形拟合 ≠ 材料恢复：本项目的核心陷阱

### 9.1 证据阶梯（六层，必须逐层过）

$$\underbrace{\text{训练外材料波形}}_{1}\to\underbrace{\text{局部材料响应}}_{2}\to\underbrace{\text{物理梯度方向}}_{3}\to\underbrace{\text{真实失配下降}}_{4}\to\underbrace{\text{材料恢复}}_{5}\to\underbrace{\text{同质量总成本}}_{6}$$

**为什么不能跳层**：一层通过只说明那条约束满足，**不自动**保证下一层。最典型的是：

> **波形误差小，不自动意味着反演成功。** 必须**单独**检查梯度质量、优化稳定性与反演结果。

### 9.2 实测证据：代理失配的排名 ≠ 材料恢复的排名

[[FNO固定网格材料恢复对照 2026-10-09]]（**实验事实**）：

| 目标／方法 | 代理**自己**的散射接收误差 | 选中材料的**物理**散射接收误差 |
| --- | ---: | ---: |
| .4／width8 | 5.688% | **0.000628%** |
| .4／训练线性 | **5.323%（更小）** | 2.643%（**更差**） |
| .6／width8 | 4.817% | 3.223% |
| .6／训练线性 | **4.068%（更小）** | 3.181% |

$\Rightarrow$ **训练线性插值报出的自身损失更小，却在目标 .4 上给出更差的材料。**
这句话是整页笔记最重要的结论之一：**"谁的波形误差小"不能用来预测"谁的材料恢复好"。**

### 9.3 实测证据：连数值执行精度都会制造假失败

[[有限孔径FWI神经算子证据审查与最小实验 2026-10-09]] + [[FNO执行精度与材料导数对照 2026-10-09]]：

| 方法 | 状态 | 默认执行 $\epsilon$=.001/.0005 | IEEE float32 $\epsilon$=.001/.0005 | IEEE 两档变化 |
| --- | --- | --- | --- | ---: |
| width4 | .4 | 34.81%／39.94% | 31.81%／31.80% | 0.0195% |
| **width8** | .4 | 16.98%／29.24% | **9.77%／9.77%** | **0.0159%** |
| **width8** | .6 | 19.70%／34.36% | **10.42%／10.42%** | **0.0188%** |
| 训练线性 | .4 | 5.954%／5.954% | 同默认 | 0.0032% |

- 自身 AD/FD 相对差从约 **2% 降到 0.002%**；两档 $\epsilon$ 变化从 **30–36% 降到 0.016–0.020%**；
- 中心预测只变 **0.066%／0.054%**；
- 结论：上一轮"导数失败"的**主因是数值执行精度**（TF32 等），**不是**物理导数错误。

> [!warning] 这条结论的边界
> 没有内核级追踪，所以只能说"**该后端精度策略影响了结果**"，**不能**声称定位了某个具体 TF32 内核；IEEE float32 也**不是**双精度真值。

### 9.4 实测证据：先修正"值偏置"也救不回来

| 实验 | 唯一改动 | 结果 |
| --- | --- | --- |
| [[FNO固定网格材料恢复对照 2026-10-09]] | 0.01 候选网格 | width8 **.40／.59**；线性 .41／.61；物理 .40／.60 |
| [[FNO材料恢复局部网格细化 2026-10-09]] | 步长 0.01→**0.002** | width8 .402／.590；线性 .410／.606；物理 .400／.600 → **偏移持续，不全由粗网格造成** |
| [[FNO训练均值残差校正对照 2026-10-09]] | 减训练三材料**均值残差** | .404／.598 → **.4 变差、.6 改善**；波形都改善 → **不能判为成功** |
| [[FNO训练仿射残差校正对照 2026-10-09]] | 再减**仿射（随 a 线性）**残差 | .406／.596 → 相对常量**两处都更差** → **停止提高校正阶数** |

**诊断（探索性分析）**：用上轮 IEEE 小 $\epsilon$ 切向 $J$ 与中心残差 $e$ 估计局部偏移

$$\delta a_{\mathrm{lin}}=-\frac{\langle J,e\rangle_t}{\langle J,J\rangle_t},\qquad e=\widehat F(a_*)-d$$

| 方法／目标 | 残差投影预测偏移 | 粗网格实际偏移 |
| --- | ---: | ---: |
| width8／.4 | +.001307 | 0 |
| width8／.6 | −.009883 | −.010000 |
| 线性／.4 | +.010361 | +.010000 |
| 线性／.6 | +.006695 | +.010000 |

$\Rightarrow$ **支持"值残差沿材料切向的投影移动了目标极小点"这一解释**（符号与量级都对上），但这是**局部线性化**，不是全区间证明。

> [!danger] 禁止的两件事
> ① **禁止**用开发真值残差给代理做 oracle 修正；
> ② **禁止**在同两个开发目标上反复升阶直到结果变好（这违反预定停止条件）。

## 10 易错点清单（每条都能在讨论中加分）

| 容易说错 | 正确说法 |
| --- | --- |
| "$\gamma$ 图就是声速图" | ❌ $\gamma$ 是**密度缩放**、$c_0$ **固定**；**不能**与 P01 的声速场逐像素比较 |
| "我们复现了 FMC" | ❌ 4 发射/24 接收 = **有限孔径**，受 PAUT/FMC **启发**，**不是**完整 FMC |
| "当前正演 = 真实物理" | ❌ 缺有限阵元尺寸、发射延时、阵元方向性、纵横波转换、耦合层、衰减、仪器响应 |
| "训练/验证随便分" | ❌ 必须按**独立工件/介质实例**划分；同一工件的 4 个源**必须同组** |
| "失配降了就是反演成功" | ❌ 观测有模型差异时，**真值甚至未必是当前离散失配的最优点** |
| "波形误差小 → 反演会成功" | ❌ 必须**单独**检查梯度、优化稳定性与反演结果 |
| "TFM 图不清晰" | ❌ 两者**物理量不同**，只能在各自定义下比 |
| "网格越细越准/越独立" | ❌ 作者**故意**用不同网格作参考以减轻 inverse crime；稠密 ≠ 独立 |
| "IEEE float32 就是真值" | ❌ 它只是更稳定的 float32；**不是**双精度真值 |
| "两次差分稳定就是局部 Jacobian 正确" | ❌ 有限幅度差分 ≠ 已验证的局部 Jacobian；数值稳定只是**必要**条件 |

## 11 与项目的关系

1. **这个试验台的价值**是提供一个"**可被加速、且可信**的参照系"。没有它，后面所有代理的加速声明都没有意义。
2. **"有限孔径"是研究难点的主要来源**：弱响应、方向混淆、观测不足 —— 这些不是 bug，是**问题设定本身**。
3. **六层证据阶梯**正是为了防住"波形好但材料错"这个陷阱，而这个陷阱**已被本项目实测证实存在**（第 9.2 节的表格）。
4. **当前卡点**：第 4 层（真实失配下降）已做到并发现**代理自身损失排名 ≠ 材料恢复排名**；第 5、6 层（材料恢复、同质量总成本）**尚无证据**。

## 12 自测（先闭卷，再回上文核对）

1. 为什么"神经算子加速"必须建立在一个**可信的传统 FWI 参照**之上？参照不可信会出现哪两种"假胜利"？
2. 为什么本项目的重建图**不是**声速图？这会影响它和 P01 的比较方式吗？
3. 一次 FWI 迭代为什么要**两倍**于一次正演的成本？这个成本可以怎么省？
4. "六方向响应范数比"里缺陷内部只有约 $2.9\times10^{-5}$。它能证明"缺陷不可恢复"吗？为什么？
5. 用第 9.2 节的表格说明：**为什么"代理自身损失更小"不能推出"材料恢复更好"**？
6. 为什么"两档 $\epsilon$ 的响应变化从 30% 降到 0.02%"这件事，足以推翻上一轮"导数失败"的结论？

> [!tip]- 自测要点
> 1. 假加速＝替代了本来算错的正演；假精度＝代理误差被参照误差掩盖。
> 2. $\gamma$ 是密度缩放、$c_0$ 固定 → 不是声速；因此只能比较"任务与证据设计"，不能逐像素比输出。
> 3. 迭代 = 1 次正演 + 1 次伴随；可用代理替代正演/伴随，但要单独验证导数质量。
> 4. 不能。那只是**选定六个方向**的**局部**证据；且缺陷 $\gamma$ 本身极小，相对扰动对应的**绝对**变化也极小。
> 5. 因为训练线性在 .4 上报出更小的自身散射接收误差（5.323% vs 5.688%），却在物理上给出更差的材料（2.643% vs 0.000628%）。
> 6. 因为只改**执行精度**、冻结权重与数据，两档稳定性与自身 AD 一致性**同时**恢复；说明原失败主要来自数值执行，而不是物理导数。
