## 1. 总目标

建立一个面向有限孔径相控阵超声无损检测的物理约束闭环系统，使算法能够：

1. 从当前 FMC/稀疏阵列数据提出缺陷候选；
2. 估计候选的不确定性；
3. 选择下一组最有价值的发射和接收条件；
4. 用物理正演或真实测量验收候选；
5. 在相同漏检率、定位误差和材料/尺寸误差下，减少物理计算或采集次数。

研究目标不是证明某个网络普遍优于传统方法，而是回答：

> 在有限孔径和测量预算约束下，物理约束神经代理能否可靠地决定“下一次测什么、验什么”，并带来可核查的总成本收益？

## 2. 项目定位

### 保留的主基线

- 有限差分或 CIVA/实验仪器正演作为最终物理验收。
- 名义割线、网格搜索、TFM或传统成像作为简单竞争基线。
- 直接 FNO 仅作为候选提议器，不再作为完整正演替代器。

### 新系统的角色划分

| 模块 | 作用 | 不允许的解释 |
|---|---|---|
| FNO/PINO | 预测可观测接收散射、候选排序 | 不称为精确正演 |
| PINN/可微物理 | 约束方程、边界、阵元和仪器参数 | 不把低PDE残差直接等同检测成功 |
| Learned Primal-Dual | 展开数据一致性和物理更新 | 不绕过最终物理验收 |
| 不确定性模型 | 判断是否拒绝代理、是否追加测量 | 不把置信度当作真实性证明 |
| 主动采集策略 | 选择下一发射/接收配置 | 不用最终真值选择动作 |
| 物理求解器/仪器 | 最终确认候选和材料/尺寸 | 成本必须计入总账 |

## 3. 研究对象与数据接口

### 第一阶段物理对象

保持当前二维有限差分接口，先使用标量声速/密度或等效材料参数，避免一开始把弹性波、模态转换、三维几何和仪器误差全部混在一起。

### 第二阶段物理对象

增加至少一种真实仪器因素：

- 阵元幅值/相位不一致；
- 探头倾角或耦合层变化；
- 曲面边界；
- 弹性波和模态转换；
- CIVA或实验 FMC 数据接口。

### 输入

- 阵元坐标和有效孔径；
- 发射波形、中心频率和激励相位；
- 接收通道及其噪声/增益信息；
- 背景材料或先验范围；
- 当前候选缺陷的参数化表示；
- 已采集的 FMC、稀疏子阵或多角度数据。

### 输出

- 接收通道散射波形；
- TOF、相位、幅值和频带特征；
- 缺陷位置、尺寸、材料/对比度的候选后验；
- 代理不确定性；
- 推荐下一次发射和接收配置；
- 物理验收触发标记。

## 4. 四阶段执行路线

### 阶段 A：重建可复现物理基线

目标：建立所有后续比较都能复用的“仪器—物理—测量”接口。

工作：

1. 固定 source、阵元位置、接收通道、波形和时间采样；
2. 保存背景场、缺陷散射场和接收测量算子；
3. 固定零散射、名义割线、全物理粗网格和传统成像基线；
4. 将每次实验的输入哈希、物理调用次数、网络前向次数和总耗时写入账本；
5. 增加噪声、增益、阵元失配和有限孔径的可控开关。

验收：

- 同一协议可重复得到相同波形和误差；
- 物理基线在不同材料和支持位置上无异常崩溃；
- 不使用最终真值选择停止条件；
- 所有新实验使用新目录，旧结果不覆盖。

### 阶段 B：可观测散射代理

目标：让网络先学会“仪器真正测到什么”，不直接输出缺陷图。

模型顺序：

1. 名义物理/线性散射参照；
2. 基础 FNO 接收散射代理；
3. 散射残差 FNO；
4. 加入波动方程、边界和接收测量约束的 PINO；
5. 需要时再加入局部 U-Net 或多尺度残差模块。

训练/验证划分：

- 训练：支持位置、尺寸、材料和阵列配置的部分组合；
- 验证：未见材料或未见位置；
- 最终测试：完全新目录、新几何或真实/CIVA数据；
- 开发数据不得重复称为独立最终测试。

验收指标：

- 完整接收波形相对误差；
- 散射接收波形相对误差；
- 局部散射场误差；
- TOF/相位/幅值误差；
- 有限差分材料差分与网络Jacobian方向余弦；
- 代理误差在不同阵元和频带上的分布。

直接代理资格线：

- 接收散射误差 ≤ 20%；
- 局部响应方向余弦 ≥ 0.9；
- 对未见材料/位置不出现系统性漏检；
- 任何一项失败都不能把网络称作物理正演替代器。

### 阶段 C：不确定性与主动采集

目标：让系统知道什么时候不能信任代理，并选择下一次测量。

先实现最小版本：

- 三个固定候选采集动作：全孔径、左半孔径、右半孔径；
- 三个候选动作产生的预测接收响应；
- 深度集成或异方差输出给出代理不确定性；
- 用候选之间的预测差异和不确定性计算信息增益；
- 当代理/物理残差不一致时触发拒绝和物理验收。

不使用的额外自由度：

- 不一开始学习连续阵元轨迹；
- 不用最终真值调信息增益权重；
- 不同时改变网络结构、损失、采集动作和停止阈值。

主动策略验收：

- 与固定全孔径相比，保持相同漏检率；
- 材料/尺寸误差不恶化；
- 追加采集次数或物理调用次数下降；
- 在代理不确定时能够拒绝，而不是输出高置信错误。

### 阶段 D：展开式闭环反演

目标：在阶段 B、C通过后，才将 Learned Primal-Dual 作为可解释反演迭代器加入。

每一层包含：

1. 当前缺陷参数或场；
2. 物理测量算子；
3. 数据残差和伴随/近似梯度；
4. 学习到的近端更新；
5. PINO物理残差和边界校正；
6. 不确定性与停止/拒绝判据。

比较：

- 物理梯度下降；
- 名义割线/低维优化；
- Learned Primal-Dual；
- Learned Primal-Dual + PINO；
- R2候选提议器作为外部初始化。

停止标准：

- 同质量材料误差下的物理调用次数；
- 全部迭代和网络训练摊销后的总时间；
- 未见材料和未见几何的稳定性；
- 物理残差、接收残差和材料误差是否同时下降。

## 5. 最小首个实验

先完成一个不涉及完整反演的主动采集实验：

- 目标：未见缺陷位置、尺寸和材料；
- 动作：全孔径、左半孔径、右半孔径；
- 代理：冻结 R2 或新的散射残差代理；
- 验收：有限差分物理正演；
- 基线：固定全孔径 + 名义割线；
- 预算：网络前向 ≤ 30 次，物理验收 ≤ 15 次，训练更新 0 次；
- 记录：漏检率、定位误差、材料/尺寸误差、拒绝率、追加采集次数、物理调用次数、总时间。

成功条件：

1. 漏检率不高于固定全孔径基线；
2. 材料/尺寸误差不高于基线的预设容差；
3. 平均物理调用或采集次数至少减少；
4. 代理不确定时触发物理验收；
5. 所有判据在运行前冻结。

失败条件：

- 漏检率上升；
- 真实目标不在代理候选集合；
- 只改善波形却恶化材料误差；
- 只减少网络时间而增加物理验收总成本；
- 代理不确定性与实际错误无关。

任一失败都意味着保留物理基线，不继续增加网络复杂度。

## 6. 论文与成果路线

### 论文主问题

“有限孔径相控阵超声检测中，物理约束可观测散射代理和主动采集能否在相同检测可靠性下减少物理计算或采集成本？”

### 预期贡献

- 相控阵仪器测量算子与神经算子结合的可复现接口；
- 散射残差而非完整波场的代理建模；
- 代理不确定性驱动的物理验收/追加采集；
- 同漏检率、同材料误差下的总成本评价；
- 失败边界和拒绝机制，而非只报告成功案例。

### 不能宣称

- 网络替代完整正演；
- FNO普遍优于传统FWI；
- 未见材料和真实仪器上已完成泛化；
- 已完成盲缺陷识别；
- 单次推理加速等于总成本下降。

## 7. 触发条件与停止条件

重新扩大网络规模的必要条件：

- 新实验在未见材料/几何上通过直接代理资格线；
- 主动策略在至少多个独立批次中减少物理调用或采集次数；
- 物理残差、接收残差和材料误差同步改善；
- 训练成本和部署成本已纳入同质量总账。

停止或转向物理基线的条件：

- 连续独立批次漏检；
- R2/PINO均不优于名义割线；
- 不确定性不能识别代理失败；
- 主动采集没有带来可靠的检测成本收益。
