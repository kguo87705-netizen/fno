## 带读路线：只学后续超声论文需要的部分

### 第 1–3 页：作者为什么提出 FNO

作者的核心问题不是“怎样解一个 PDE”，而是“怎样对一大批相似但输入条件不同的 PDE 快速重复求解”。传统有限差分和有限元每遇到一个新输入都要重新计算；普通 CNN 通常把数组当作固定尺寸的向量或图像；PINN／Neural-FEM 往往针对一个新方程实例重新优化。FNO希望训练一次后学习一个问题族的解算子：

```text
输入函数 a(x)  ── 学习到的算子 G ──> 输出函数 u(x)
```

在本论文中，`a` 可以是 PDE 的初始条件或系数场，`u` 是对应解。它与后续超声文献的关系是：

```text
P05: 厚度图 h(x,y)                 -> 完整时空波场 w(x,y,t)
P06: 厚度图 h(x,y) + 初始波场 w0    -> 完整时空波场 w(x,y,t)
P01: FMC 数据 d(e,r,t)             -> 纵波声速场 cL(x,y)
```

暂时不要深究“Banach 空间”“无穷维”等泛函分析术语。把它理解为：输入和输出不是几个数字，而是定义在连续空间或时间上的一整张场。

### 第 4–6 页：网络和 Fourier layer

整网由三部分组成：

```text
a(x) -- P --> v0(x) -- 多个 Fourier layer --> vT(x) -- Q --> u(x)
```

- `P`：逐位置增加特征通道，不是把图像放大。
- Fourier layer：每层同时使用全局 Fourier 分支和局部线性分支。
- `Q`：把隐藏特征投影为最终物理量。

最小公式是：

```text
v_next = activation( local_branch(v) + global_Fourier_branch(v) )
```

Fourier 分支的四步：

```text
空间特征 v -> FFT -> 保留部分 Fourier 模式并乘以可训练复数权重 R
           -> IFFT -> 回到空间特征
```

每一个 Fourier 系数由全域的信息共同计算，逆变换后又会影响全域位置，因此远距离位置可以在一层中相互联系。`Wv` 是局部线性分支，帮助保留局部信息，并缓解非周期边界带来的问题。多层 Fourier layer 之间的非线性激活使模型能够逼近非线性算子。

### 第 9 页：两个容易误解的结论

**零样本超分辨率**：论文在 `64×64×20` 数据上训练、在 `256×256×80` 数据上评估。这里改变的是同一物理问题的采样网格，不能推出模型能够自动适应新的材料、激励频率、源位置或缺陷分布。

**截断模式并非“只能输出低频”**：每层只直接学习有限个低 Fourier 模式，但局部分支、非线性和最后的解码器能够恢复部分高频成分；不过局部急剧变化仍然较难。这正是 P05使用残差精修与更多模式、P06使用 U-Net局部几何编码、P01在 U-Fourier层中加入 U-Net分支的背景。

### 与 P05/P06/P01 的一句话联系

本论文提供的是“快速学习一族函数到函数映射”的基本骨架；P05针对缺陷散射的局部误差增加第二阶段，P06把局部缺陷编码和时空传播结合，P01把同一思想转向 FMC 到声速场的逆映射。
